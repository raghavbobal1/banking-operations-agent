# Banking Operations Agent

A recruiter-facing AI banking operations project inspired by the 27-minute Spring AI / AWS Bedrock / MCP tutorial.

## Product direction
A polished banking operations workspace with synthetic accounts and transactions, support-case workflows, and an auditable tool-execution timeline.

## Current status
The repository has been initialized. The first UI is a **local simulation**, not a live AI agent or connected banking system. No real customer data is used.

## Planned architecture
- **Frontend:** responsive browser-based operations console
- **Backend:** Java 21 / Spring Boot
- **Agent:** Spring AI with AWS Bedrock, with a mock fallback for local development
- **Tools:** MCP-style account lookup, transaction lookup, support-case creation
- **Quality:** tests, audit events, documented environment setup, CI

## Milestones
1. Interactive synthetic-data UI
2. Java REST backend and tests
3. Spring AI / Bedrock integration and tool execution
4. Deployment, screenshots and portfolio case study

Do not use this demo for real financial decisions.
